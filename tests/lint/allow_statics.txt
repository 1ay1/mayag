# Mutable `static` variables in include/mayag/, and why each is safe.
# A static that is not const is state every runtime and thread in the
# process shares -- the classic hidden race. Read-only data is `static const`
# (or constexpr); shared caches are `static Cell<T>`; per-thread frame state
# is thread_local (banlist-gated). Anything else needs a line here.
# Checked by tests/lint/statics.sh (ctest mayag_shared_statics); a line that
# no longer matches anything fails the same test, so the list cannot rot.
